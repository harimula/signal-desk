What every bot setting does

One entry per control on the Bot settings tab: what it changes, the default, and when you'd move it. Defaults marked tested are the values the 33-year research used; anything marked experimental was never backtested.

Kept in step with the settings tab on every change · last updated 2026-10-23 (test alert button, morning alert)

How settings workwhere they live and when they take effect

Settings are saved to the file bot/config.json in your GitHub repo. The bot re-reads that file once a minute while it runs, so most changes take effect within about a minute, without a restart. Three things only happen when a bot session starts (9:20 AM ET on weekdays, or when you press Run the bot now): loading new bot code, reading the keys, and the market scan.

Values outside the allowed range are clamped to the nearest limit. Anything you type that the bot doesn't recognise is ignored. The sticky bar at the top shows unsaved changes until you press Save settings to the bot.

1 · Connectionyour GitHub repo, broker keys and alerts

GitHub token

Stored in this browser only

A fine-grained personal access token that lets this page write the settings file, the keys and the pause file to your repo. Needs Contents, Secrets and Actions: Read and write on this one repo. Make it expire within 90 days and make a new one when it does.

Test connection tells you how fast GitHub answers, whether the token works, when it expires, and how many API calls are left this hour. Use it first whenever a save misbehaves.

Alpaca API key / secret

Encrypted GitHub secrets · paper keys

The paper-trading keys from your Alpaca dashboard. They are sealed in your browser with GitHub's public key and stored as encrypted secrets; this page never sees them again and they are never written to the repo. The bot reads them when a session starts.

Phone alert topic

Encrypted secret · optional

A secret channel name for the free ntfy app. Subscribe to the same name on your phone and every trade, stop and error arrives as a push notification. Pick something nobody could guess; anyone who knows the name can read the alerts.

Enter just the name (my-topic) or paste the whole link from the app (https://ntfy.sh/my-topic) — both work. Anyone who knows or guesses the name can read the alerts, so a random name is safer than a word.

Send test alert (under the box): type the topic and press it — the page posts a test message straight to ntfy.sh, so you can confirm the app is subscribed before any trade happens. The saved topic is a secret this page cannot read back, which is why the test uses what you type. Every morning the bot also sends one “Bot is up for the day” alert, so a quiet phone means nothing happened, not that alerts are broken.

Journal passphrase

Encrypted secret + saved in this browser · 12+ characters

Encrypts the bot's trade journal before it is published on the (public) site, and encrypts your synced settings. The Bot trades tab asks for the same passphrase on each device to unlock. Changing it means every device must enter the new one — and the old journal file can no longer be opened by the page.

Live API key / secret

Encrypted secrets · real money only

Leave empty for paper trading. Only used when section 7 is switched to real money; a paper key is rejected by the live endpoint, so the two can't be mixed up.

Sync across devicessettings follow you

With a token and the journal passphrase entered, your Finnhub/FMP keys, watchlist, portfolios and calculator inputs are encrypted with the passphrase and stored in the repo, so a second device with the same passphrase gets them automatically. 👤 Sign in (top of the page) is the normal way to use another device: enter the passphrase and that device gets your token, keys, holdings and settings, then stays in sync. Sign out and wipe this device clears a borrowed computer. Link a phone — show QR code is the alternative: scan it with the phone's camera and the token, passphrase and price keys install themselves; holdings, watchlist and settings arrive seconds later and sync automatically from then on. The code carries your secrets — show it only to your own phone. Show / copy the passphrase remains for pasting it by hand.

2 · Risk profilehow much the bot may lose, per trade and in total

Profile: Conservative / Balanced / Aggressive

Default Balanced tested

A preset that fills in every number in this section and in Capital allocation at once. Editing any of those numbers switches the profile to Custom; picking a profile again resets them.

Conservative: 0.25 % risk, 1.5 % cap, 4 stocks, 1 option. Balanced: 0.5 %, 3 %, 6 stocks, 4 options. Aggressive: 1 %, 6 %, 8 stocks, 6 options.

Risk per stock trade

Default 0.5 % · range 0.05–3 %

How much of the account one stock trade may lose if the price falls to its stop. The bot sizes the position so that (shares × distance to the stop) equals this. It is usually the number that decides how many shares get bought — smaller than the capital-per-position limit.

Raise it to take bigger positions; lower it if a string of losses would bother you. 1 % is the common ceiling among professionals.

Risk per option trade

Default 0.5 % · range 0.05–3 %

Same idea for CALLs and PUTs: the number of contracts is chosen so that hitting the option stop (−50 %) loses at most this share of the account.

Total risk cap

Default 3 % · range 0.5–15 %

The most the account can lose if every open position hits its stop at once. When a new trade would push the total above this, it is skipped and the log says so.

Max positions per sector

Default 2 · range 1–10

Stops the bot from loading up on one industry (e.g. three chip stocks that all fall together). Only applies to stocks whose sector the bot knows; names it doesn't know count as "Other" and are not limited.

Daily loss limit

Default 3 % · range 0.5–20 %

If the account is down this much on the day, the bot stops opening new trades until tomorrow and closes its options. Open stock positions are kept and managed as usual.

Weekly loss limit

Default 6 % · range 1–30 %

Down this much since Monday's open: no new trades until next week.

Losing streak limit

Default 3 · range 1–10

This many losing trades in a row today and the bot is done for the day. Protects against a tape where nothing works.

3 · Capital allocationhow much money each of stocks, CALLs and PUTs may use

Money the bot works with (your stake)

Default empty = the whole account

Enter the amount you actually intend to trade with. Every position size, the daily and weekly loss limits and the pattern-day-trader rule are then computed on that figure instead of the practice account's $100,000 balance, and the Bot trades tab shows profit and loss against it. The practice account then behaves exactly like that much real money.

Trade stocks / Trade CALL options / Trade PUT options

Default on / on / off · PUTs experimental

Switch each instrument on or off. Stocks are the researched core. CALLs ride the same dips with options (limited loss, more leverage). PUTs are the mirror image — bought when a stock in a downtrend spikes — and were never part of the research.

Size it in: % of account / fixed dollars

Per instrument · default % of account

Choose whether the money limits for that instrument are read as a percentage of the current account value or as fixed dollar amounts. The pair you don't pick is dimmed and ignored.

Per trade (%, or $)

Defaults 10 % stocks · 2 % CALLs · 1 % PUTs · or $10,000 / $2,000 / $1,000

The most one trade may spend. The actual size is the smaller of this and the risk-per-trade rule above. If even one share or one contract costs more than this, the trade is skipped and the log says "above this trade's money budget".

All together (%, or $) — 0 = no limit

Default 0

A ceiling on everything that instrument holds plus its waiting buy orders. With $400 on PUTs and $300 already in PUT positions, the next PUT may use $100 at most.

Handy for keeping the experimental sleeves small while you test them: e.g. PUTs capped at $500 in total.

Max stock positions

Default 6 · range 1–20

How many different stocks it will hold at once. Note the research used 6; fewer concentrates, more dilutes each signal.

Max option positions (CALLs + PUTs)

Default 4 · range 0–10

Shared cap across both option kinds.

4 · Strategythe tested values are the defaults — change with care

Intraday signals

Default off experimental

Off: a stock has to finish a day as a sharp dip; the bot sees it the next morning. On: the live price stands in for today's close, so a stock that falls hard at 11 AM can qualify at 11 AM. Same thresholds, more trades, more false alarms (a dip at 11 AM can recover by the close). The "already bounced 1 %" rule still uses yesterday's real close.

RSI-2 buy level

Default 10 tested · range 2–30

RSI-2 scores the last two days from 0 (fell hard) to 100 (rose hard). A stock above its 200-day average qualifies as a dip when RSI-2 is below this number. PUTs use the mirror: below the 200-day and RSI-2 above 100 minus this number (90 by default).

Raise it (15–25) to get more, shallower dips and more trades; lower it (5) for only the sharpest dips. The research found 10 the best balance.

Max hold

Default 10 sessions tested · range 1–30

A position that hasn't bounced above its 5-day average by then is sold anyway.

Option take-profit

Default +50 % · range 10–300 %

An option that gains this much is sold (a resting limit order sits at the broker, so it fills at exchange speed).

Option stop

Default −50 % · range 20–90 %

An option that loses this much is sold. Options also leave 3 days before expiry and on Fed-decision afternoons regardless.

Hard floor

Default 25 % · range 5–60 %

A stock down this much from its buy price is sold immediately, any time of day, streamed tick by tick. It is a disaster brake, not the normal exit — the normal exit is the 5-day-average bounce.

Cancel unfilled entries after

Default 45 minutes · range 5–240

A buy order that hasn't filled (the price ran away) is cancelled after this long so money isn't tied up.

Entry window closes at

Default 11:00 AM ET tested · range 10:00–15:00

New positions are opened only between 9:45 AM (10:15 on CPI/jobs mornings) and this time. Positions are managed all day regardless. The research entered in the first hour; a later close gives more chances but drifts from what was tested.

4b · Day tradingin and out the same day — experimental

Everything here follows the day trading rulebook: opening-range breakouts and VWAP pullbacks on 5-minute bars, longs only while SPY is above its VWAP, shorts only below it, stop before entry, 2R targets, breakeven at +1R, flat by 3:50 PM. Not part of the 33-year research; paper-test it and keep the sleeve small.

Day-trade

Default off experimental

The master switch. Off, the bot only swing-trades; open day trades, if any, are still managed to their exits.

Long setups → buy shares / buy a CALL instead · Short setups → buy a PUT

Default on / off / on

Which instrument carries each side. The bot never shorts stock, so a short setup is a PUT or nothing. Shares and CALL can both be on (then a long setup places a share buy; CALLs are used when shares are off).

Opening range

Default 15 min · range 5–60

How many minutes after 9:30 define the opening range for the breakout setup. 15 and 30 are the common choices; the research tests both.

Put these values in the form (research)

Appears once the day-trading research has run

Copies the best-tested combination (range, relative volume, target, time stop, window) into the form. You still press Save. The test and its caveats are on the Bot trades tab.

Max day trades per day

Default 3 · range 1–10

Across all stocks; one trade per stock per day, no re-entry after a stop.

Losses in a row that end the day

Default 2 · range 1–5

Counts same-day round trips only.

Risk per day trade

Default 0.5 % · range 0.1–2 %

Shares (or contracts) are sized so the stop loses at most this share of the account, then capped by the Capital allocation money limits.

Target

Default 2 R · range 1–4

Reward as a multiple of the risk. 2 means the target is twice as far as the stop.

Minimum relative volume

Default 1.2× · range 0.5–3

Today's volume so far versus a normal day by this time. Below it the stock is not "in play" and no setup is taken.

Time stop

Default 60 min · range 15–180

A trade that is not at least 0.3R in profit after this long is closed.

Option take-profit / Option stop

Default +50 % / −40 %

On the option's own price, for day-traded CALLs and PUTs; the stock-level stop and target apply too.

Option expiry, max days out

Default 7 · range 1–14

Nearest expiry at least one trading day away and at most this many days out — never same-day (0DTE). Strike nearest the money; spread must be under 10 %.

Entries from / until

Default 09:45–15:30 ET

Earliest 9:35 (the 15-minute opening range must be complete first), latest 15:45. Exits run all day; everything is flat by 3:50 PM (options 3:45).

5 · Guardswhat makes the bot stand aside

Economic calendar guard

Default on

No new trades around Fed decisions (from 30 min before to 60 min after, options closed before), CPI and jobs mornings (entries from 10:15, half size until 11:00) and Fed-minutes afternoons. The calendar is in events.json through 2027.

Breaking-news guard

Default on

Scans headlines every minute. A fresh war / policy / crisis headline pauses new trades for 30 minutes; a stock with its own fresh news or earnings is skipped. Matching is whole-word and phrase-based ("Radware", "awards", "software" cannot trigger it; "invasion", "missile strike" can). The Bot trades tab shows exactly which headline it reacted to.

Phone alerts

Default on · needs the alert topic in section 1

Sends every buy, sell, daily/weekly stop and error to your phone, a “Bot is up for the day” alert each morning and the day summary after 4 PM. No trades means no trade alerts.

Include prices and profit in alerts

Default on

Buys show size and limit price; sells show the entry price, the exit price and the profit. Turn off if you want alerts without numbers (anyone who knows your topic name can read them).

6 · Stocks it watchesthe universe

Scan the whole market

Default off (uses your list)

Each session start the bot asks the broker for every tradable US stock on NYSE / NASDAQ / ARCA / AMEX (no OTC), ranks them by 20-day average dollar volume, drops anything under the minimum price, and watches the top N. The Bot trades tab shows the list it picked. Your typed list is ignored while this is on. The scan happens only at session start, so a change here shows up at the next start.

How many stocks to watch

Default 200 · range 50–400

The size of the scanned list. The strategy was tested on large, liquid names, which is why ranking by volume is the filter.

Minimum share price

Default $5 · range $1–500

Skips penny stocks. A high value (say $50) narrows the scan to larger companies.

Only my list

Default list: 30 large US names

US tickers, comma-separated, up to 60. Positions are managed even if a ticker is removed from the list.

7 · Modepaper or real money

Ready for real money? (checklist)

Computed from your actual data

Nine checks: paper history, closed trades, live expectancy versus the research, drawdown, broker-side stops, alerts and watchdog, live keys, live size, experimental sleeves. It never blocks the switch; it tells you what a professional would want to see first. The full procedure is in the documentation under Operations → Going live.

Live size

Default 25 % · range 5–100

In real-money mode every budget and risk figure is multiplied by this. Start at 25, raise it month by month while the results hold. Paper mode is always 100 %.

Trade real money

Default off (paper)

Switches the bot to the live Alpaca keys from section 1. It refuses unless you also type I UNDERSTAND THE RISK. Paper keys never trade real money. Only consider this after the checklist above is green, and never run two bots on one account. Every stock entry carries its protective stop at the broker, and the watchdog alerts your phone if the bot goes silent.

8 · Controlspause, resume, run

Pause — sell everything now

Not a pause button in the gentle sense: within seconds the bot cancels every order and sells every position, then stays idle until you press Resume. Use it when you want to be flat right now.

Run the bot now

Starts a fresh bot session on GitHub Actions on the latest code. The running session, if any, continues until it ends; the new one waits in the queue unless the old one is cancelled on GitHub. This is also how new bot code and a market-scan change take effect before tomorrow.

Re-run 33-year research

Starts the strategy-research workflow (about 40 minutes). Results appear on the Bot trades tab.

Reload from GitHub

Throws away unsaved edits and re-reads the saved settings.

Common setupswhat to change for what you want

"I want to see it trade more, it's paper anyway"

RSI-2 buy level 20–25 · Entry window 15:00 · Intraday signals on · Scan the whole market, 200 stocks · Max stock positions 10. Expect more, shallower trades and a result that no longer matches the research.

"Test puts and intraday without risking much"

Keep the core at its defaults; set PUTs to fixed dollars, $200 per trade, $600 all together; same for CALLs. The experiments stay small while the tested rule runs at full size.

"Run exactly what was tested"

Profile Balanced · PUTs off · Intraday off · RSI-2 level 10 · Entry window 11:00 · Only my list (the 30 defaults) · Max hold 10.

"Something's wrong, make it stop"

Section 8 → Pause. Everything is sold within seconds. Resume when you're ready.
